# Assignment 6 – The Laplace Transform

## Course

EE2703 – Applied Programming Lab

## Objective

This assignment studies the analysis of continuous-time Linear
Time-Invariant (LTI) systems using Laplace transforms and Python's
signal-processing tools.

The problems include mechanical systems as well as an RLC network.
The assignment uses transfer functions, impulse responses, system
simulation, and frequency-response analysis.

## Learning Outcomes

After completing this assignment, I learned to:

- Represent LTI systems using transfer functions
- Use Laplace-transform based system models
- Define polynomial transfer functions
- Compute impulse responses
- Simulate LTI systems using input signals
- Analyse the response of systems to different frequencies
- Solve coupled second-order systems using transfer functions
- Calculate magnitude and phase response
- Analyse an RLC network
- Use Bode plots for frequency-response analysis
- Study transient and long-term responses of an RLC circuit
