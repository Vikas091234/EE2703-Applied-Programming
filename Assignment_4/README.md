# Assignment 4 – Fourier Approximations

## Course

EE2703 – Applied Programming Lab

## Objective

This assignment studies Fourier-series approximations of the functions
e^x and cos(cos(x)).

The Fourier coefficients are calculated using two methods:

- Direct integration
- Least-squares estimation

The coefficients obtained from both methods are compared, and the
functions are reconstructed using the calculated Fourier coefficients.

## Learning Outcomes

After completing this assignment, I learned to:

- Define and analyse periodic and non-periodic functions
- Compute Fourier-series coefficients
- Use numerical integration with `scipy.integrate.quad`
- Construct Fourier basis matrices
- Perform least-squares estimation using NumPy
- Compare Fourier coefficients obtained by different methods
- Reconstruct functions from Fourier coefficients
- Use semilog and log-log plots
- Analyse the convergence of Fourier coefficients
- Understand the Gibbs phenomenon
